# 意大利旅行助手

静态 GitHub Pages 网页。入口 `index.html`。

## 部署
1. 在 GitHub 新建公开仓库，例如 `italy-trip`。
2. 上传本文件夹内的 `index.html`、`manifest.webmanifest`、`icon.svg` 和 `.nojekyll` 到仓库根目录（不是上传整个文件夹）。
3. 打开仓库 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 页面发布后访问 `https://你的用户名.github.io/italy-trip/`。
5. iPhone Safari 打开网址 → 分享 → 添加到主屏幕。

提示：不要把护照号、车票二维码、酒店预订号等私人信息直接写进公开仓库。
